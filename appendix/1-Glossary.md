# Glossary

- **RoE** — Rules of Engagement
- **ATT&CK** — MITRE ATT&CK framework (adversary tactics/techniques)
- **EPSS** — Exploit Prediction Scoring System
- **IDOR** — Insecure Direct Object Reference
- **UEBA** — User and Entity Behavior Analytics
- **Purdue Model** — ISA-95 reference architecture for OT/ICS network segmentation (Levels 0–5)
- **Tier-0** — The highest-privilege tier in an Active Directory tiered administration model (Domain Controllers, etc.)
- **Canary data** — Synthetic, tagged data used in place of real PII/PCI during exfiltration testing
